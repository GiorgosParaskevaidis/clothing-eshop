# Χάρτης αρχείων του e-shop

Ο βασικός φάκελος είναι **D:\Projects\clothing-eshop**. Άνοιξε το **Thesamenot.code-workspace** στο VS Code για να βλέπεις ολόκληρο το repository: backend, frontend, scripts, εργαλεία και οδηγίες. Το παλιό **Thesamenot-Frontend.code-workspace** περιέχει μόνο το frontend.

Το F5 στο νέο workspace ξεκινά το frontend. Το backend συνεχίζει να ξεκινά από το Visual Studio με το **Thesamenot.sln**. Αν λειτουργεί ήδη ο frontend server σε άλλο παράθυρο, δεν χρειάζεται δεύτερο F5.

## Αρχεία ρυθμίσεων που αλλάξαμε πρόσφατα

| Αρχείο | Τι ελέγχει |
|---|---|
| [Backend launchSettings.json](D:/Projects/clothing-eshop/backend/Thesamenot.Api/Properties/launchSettings.json) | Εκκίνηση από Visual Studio, θύρα 5080, Development, αυτόματο άνοιγμα browser. Το browser launch είναι πλέον απενεργοποιημένο. |
| [Frontend launch.json](D:/Projects/clothing-eshop/frontend/.vscode/launch.json) | F5 όταν έχει ανοίξει μόνο ο φάκελος frontend: Node.js debugger, θύρα 3000, άνοιγμα προεπιλεγμένου Edge. |
| [Frontend settings.json](D:/Projects/clothing-eshop/frontend/.vscode/settings.json) | TypeScript έκδοση του project και Command Prompt για terminal/tasks του frontend. |
| [Frontend tasks.json](D:/Projects/clothing-eshop/frontend/.vscode/tasks.json) | Development server, typecheck και production build. |
| [Πλήρες workspace](D:/Projects/clothing-eshop/Thesamenot.code-workspace) | Προβολή όλου του project και αντίστοιχες ρυθμίσεις F5/tasks με διαδρομές προς frontend. |
| [appsettings.Local.json](D:/Projects/clothing-eshop/backend/Thesamenot.Api/appsettings.Local.json) | Ιδιωτική τοπική σύνδεση βάσης, admin hash και ρυθμίσεις δοκιμαστικής λειτουργίας. Εξαιρείται από Git/ZIP. |
